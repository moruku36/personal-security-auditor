# 本人向けセキュリティ確認チェックリスト

このチェックリストには、パスワード、PIN、認証コード、回復コード、passkeyの秘密情報を入力・記録しないでください。画面のスクリーンショットやアカウント識別子も監査レポートやGitへ保存しません。

## Chrome拡張

- Chromeの `chrome://extensions` を開き、使っていない拡張と見覚えのない拡張がないか確認する。
- 各拡張の提供元をChrome Web Storeや開発元の公式情報で本人が確認する。
- 「サイトへのアクセス」で、すべてのサイトへのアクセスが本当に必要か確認し、不要なら限定設定にする。
- 詳細画面で要求する権限と、Chrome上で実際に許可されている権限を確認する。CLIがmanifestから読むのは要求宣言で、許可済み状態ではない。
- `chrome://policy` で管理ポリシーの状態を確認する。CLIのレジストリ検査は `ExtensionSettings` の存在だけで、適用結果の証明ではない。
- Chromeの更新状態をブラウザー画面で確認する。CLIはネットワークで拡張やブラウザーの更新を確認しない。

## MFAとpasskey

重要なアカウントごとに、本人がアカウントのセキュリティ設定を開いて確認する。

- MFA（二段階認証）が有効か、現在も使える認証手段が登録されているか確認する。
- 回復用の連絡先が本人の管理下にあるか、使えない古い連絡先が残っていないか確認する。
- passkeyの登録先と、端末紛失・買い替え時の回復方法を確認する。同期型か端末にひも付くかはサービスと設定で異なるため、そのサービスの説明を確認する。
- 見覚えのない端末や認証手段があれば、サービスの公式手順に従って本人が対応する。
- 回復コードは画面やレポートへ転記せず、サービスの案内に沿って安全に保管する。

## Windows HelloとPIN

- Windowsの「設定 > アカウント > サインイン オプション」で、本人が使うサインイン方法と端末ロック設定を確認する。
- PINをほかのサービスのパスワードと使い回さない。PINや入力内容をCLI、メモ、レポートに記録しない。
- PINの強度、端末のTPM利用状態、各アカウントのpasskey保護をこのCLIで完全に判定することはできない。必要ならWindowsと各サービスの公式画面・説明を確認する。
- 端末を紛失した場合の本人確認とアカウント回復経路を確認する。

## 結果の扱い

本人の画面で確認した結果だけを手元のメモに残す場合も、秘密情報や個人識別子は含めないでください。設定変更、passkeyの削除、MFAの解除・追加、パスワード変更は、この監査CLIからは実行しません。
